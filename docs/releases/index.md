# 릴리즈

각 릴리즈는 **같은 양식으로** 데모 영상 · 평가 수치 · 재현 절차를 남긴다. 수치를 PR 본문에만 적어두면 릴리즈 사이 비교가 불가능해진다.

릴리즈별 범위와 일정은 [홈의 로드맵 표](../index.md#로드맵)를 본다. 여기 페이지들은 "그래서 무엇이 나왔나"만 담는다.

## 양식

| 항목 | 내용 |
|---|---|
| 상태 | 계획 / 진행 중 / 완료 (완료면 태그와 GitHub Release 링크) |
| 데모 | 영상 링크. 무엇을 보여주는 장면인지 한 줄 |
| 평가 수치 | 지표 · 값 · **측정 조건**. 조건 없는 숫자는 적지 않는다 |
| 재현 절차 | 이 릴리즈 태그에서 그대로 실행 가능한 명령 |
| 관련 문서 · PR | 그 릴리즈에서 확정된 문서와 주요 PR |

평가 조건표의 축(물체 위치 격자 · yaw · seed)은 [태스크 정의 6절](../task-pick-place.md)에서 고정한다. 릴리즈 페이지는 그 조건표를 참조만 하고 새로 정의하지 않는다.
